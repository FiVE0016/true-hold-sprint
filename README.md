# 真正的按住疾跑

> 按住疾跑键才疾跑，松开立刻停 —— 而不是"按一下切换"。
> 支持全向疾跑（W / A / S / D 都能跑）。

一个 **纯客户端** 的 Fabric 模组，适用于 **Minecraft Java 26.3+**。
只依赖 Fabric Loader，**不需要 Fabric API**，服务端也不需要安装。

---

## 解决什么问题

原版有两个坑，单靠改按键绑定绕不过去：

1. **左 Shift 默认是潜行键**。你把「疾跑」也绑到左 Shift 后，按下时同时触发了潜行，而**潜行会取消疾跑** —— 于是根本跑不起来。
2. **松开疾跑键不一定停**。原版的停跑条件里不总是包含"松开疾跑键"，某些设置下（例如无障碍里的冲刺切换）松手后仍会继续疾跑。

装上之后：

| 操作 | 原版 | 装了本模组 |
| --- | --- | --- |
| 按住 W / A / S / D | 走路 / 侧移 / 后退 | 同左 |
| 移动键 + 疾跑键 | 只有按 W 能疾跑 | **全向疾跑**（前后左右都行） |
| 松开疾跑键，移动键还按着 | 状态不明确，可能仍在疾跑 | **立刻停止疾跑，继续走路** |

## 功能

### 核心

- **按住才跑、松开即停**：疾跑严格跟随疾跑键的按住状态，不做"切换式"。
- **全向疾跑**：W / A / S / D 任意方向都能疾跑。原版只允许向前疾跑，侧移和后退会被原版中途取消。
- **水下全向冲刺**：支持向前、侧移和后退冲刺游泳；松开疾跑键后停止模组触发的冲刺，移动键可以继续按着。
- **速度与视野一起生效**：疾跑的速度加成和视野（FOV）拉伸都会正常出现，不会出现"视野变了但速度没变"。
- **保留原版双击 W 疾跑**：模组只清理"自己开起来"的疾跑，原版那套双击 W 的行为完整保留，互不干扰。

### 细节处理

- **疾跑键与潜行键同键时可正常工作**：当两个键被绑到同一个物理键（例如都在左 Shift）时，按住疾跑键不会触发下蹲（下蹲会取消疾跑）。两个键分开绑时不做任何干预，潜行照常。
- **疾跑跳跃方向修正**：原版那脚起跳加速是按"视角正前方"给的，侧移或后退疾跑时按跳跃会朝前方窜一下。本模组会把它转到**实际移动方向**上，大小不变；向前跑时完全等同原版。
- **打开界面时不接管**：打开背包、聊天、暂停菜单等界面时，模组不干预按键状态。
- **水中保留原版游泳姿态与平滑 FOV**：只扩展冲刺的方向资格，不伪造前向移动、不直接改相机视野，避免普通游泳与冲刺反复切换。
- **趴下 / 鞘翅 / 骑乘 / 死亡时让行**：这些状态下将控制权交回原版，避免姿态与疾跑状态打架；水中使用独立的原版游泳路径。
- **启动自检**：进入世界约 5 秒后会在日志里确认注入是否生效。如果模组因版本不匹配而失效，日志会明确报错，而不是静默地什么都不做。

### 兼容性

- **纯客户端**：单人游戏与多人服务器都能用，服务端无需安装；联机走的是原版发包通道，没有自定义网络包。
- **不依赖 Fabric API**，也不依赖 Mod Menu。
- **水中沿用原版冲刺流程**：仅扩展方向条件并处理模组触发冲刺的松键停止，其余游泳姿态、移动和 FOV 仍由原版控制。
- **跑酷类模组兼容性尚未测试**。

## 配置

配置文件：`.minecraft/config/true-hold-sprint.json`（首次启动自动生成，改完重启游戏生效）

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| `enabled` | `true` | 总开关。关掉后行为完全等同原版 |
| `stopSprintOnRelease` | `true` | 松开疾跑键立刻停（核心功能）。关掉后只剩"全向能起跑" |
| `requireMovement` | `true` | 必须按着移动键才疾跑。关掉后单按疾跑键也会进入疾跑 |
| `allowBackwardSprint` | `true` | 允许**后退**时疾跑。关掉则退回原版：侧移可跑、后退不行 |
| `keepSprintDuringTick` | `true` | 帧内维持疾跑状态，保证速度加成也生效。关掉会变成"只有视野变、速度不变" |
| `fixSprintJumpDirection` | `true` | 疾跑跳跃方向修正（见上文）。关掉即完全按原版 |
| `suppressSneakWhileSprinting` | `true` | 疾跑键与潜行键同键时，按住疾跑键不触发下蹲 |
| `debugLog` | `false` | 在日志里打印每帧的按键与判定结果，排障用 |

---

## 安装

1. 安装 **Fabric Loader**（Minecraft 26.3 或更高版本）；
2. 把 `true-hold-sprint-<版本>.jar` 放进 `.minecraft/mods/`；
3. 启动游戏，在 **选项 → 按键绑定** 里把「疾跑」设成你想要的键（推荐 **左 Shift** 或 **左 Ctrl**）。

**版本要求**：Minecraft `>=26.3`，Fabric Loader `>=0.19.5`，Java 25。
